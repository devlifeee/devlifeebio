# Мой 3D-сайт

Персональный React + TypeScript сайт с интерактивной 3D-моделью.

## Публикация на GitHub Pages

1. Создайте пустой репозиторий на GitHub и загрузите в него содержимое этой папки в ветку `main`.
2. В репозитории откройте **Settings → Pages**.
3. В блоке **Build and deployment** выберите **GitHub Actions**.
4. После первого push сайт появится по адресу, указанному в разделе Pages.

Для локального запуска установите зависимости и выполните `npm run dev`.

3D-модель находится в `public/models/character.glb`. Для замены сохраните новую GLB-модель под этим же именем.
